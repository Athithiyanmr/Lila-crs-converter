# 🌍 GeoCRS Converter

GeoCRS Converter is a Docker-based web platform for converting Coordinate Reference Systems (CRS) of both raster and vector geospatial data.

It allows users to:
- Upload a raster (GeoTIFF) or vector (Shapefile, GeoJSON, GeoPackage)
- Automatically detect the current CRS
- Select a target EPSG code
- Reproject the data
- Download the converted output

---

## 🚀 Features

- ✅ Raster reprojection (GeoTIFF)
- ✅ Vector reprojection (Shapefile, GeoJSON, GPKG)
- ✅ Automatic CRS detection
- ✅ FastAPI backend
- ✅ Streamlit frontend
- ✅ Dockerized deployment
- ✅ Ready for cloud hosting
